# 🎮 Video Games Analytics Dashboard

Interactive Streamlit dashboard for exploring global video game sales, platform performance, genre trends, regional sales behavior, and critic/user score relationships.

This project was built as a data analysis and visualization tool using Python, Pandas, Plotly, and Streamlit.

---

## 📌 Project Overview

The dashboard analyzes a video game sales dataset and allows users to explore:

- Global and regional sales trends
- Best-selling platforms
- Best-performing genres
- Top video games by sales
- Sales distribution by region
- Critic score and user score relationships
- Platform and genre comparisons
- Yearly evolution of the video game industry

The goal is to transform raw video game sales data into clear, interactive business insights.

---

## 🧠 Business Questions

This dashboard helps answer questions such as:

- Which platforms generated the most sales?
- Which genres dominate global sales?
- How do sales differ across North America, Europe, Japan, and other regions?
- What are the most successful games in the dataset?
- Do critic scores or user scores appear to relate to sales performance?
- How has the video game market evolved over time?
